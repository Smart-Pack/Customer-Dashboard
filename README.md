# SmartPack Customer Dashboard

This repository contains the web-based customer dashboard for the SmartPack system, built with Vue 3 and Vite. It provides customers with an interface to monitor their SmartPack, view schoolbag load and posture data, track device status, review insights, and receive alerts.
