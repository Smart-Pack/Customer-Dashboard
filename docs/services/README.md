# Services

This directory contains documentation for the services used by the SmartPack Customer Dashboard. These services encapsulate reusable application functionality and integrations with external APIs and native device capabilities.

## Documentation

- [Bluetooth Serial Service](bluetooth.md) - describes Bluetooth Classic SPP communication between the Android application and ESP32-based SmartPack devices, including connection management, health monitoring, and serial data transmission.
- [Push Notifications Service](push-notifications.md) - describes browser push notification registration, subscription management, and notification handling.
- [Firebase Messaging](firebase-messaging.md) - describes Android Firebase Cloud Messaging integration, FCM device registration, and notification asset generation.
